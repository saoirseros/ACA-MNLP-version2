## Regenerating

All three scripts only need `matplotlib` (and `numpy` for the results
script), already installed in the `nlp-service` virtual environment used
elsewhere in this project:

```powershell
cd paper_figures
C:\nlp-venvs\ptp-nlp-service\Scripts\python.exe make_figure1.py
C:\nlp-venvs\ptp-nlp-service\Scripts\python.exe make_figure2.py
C:\nlp-venvs\ptp-nlp-service\Scripts\python.exe make_results_figures.py
```

`make_results_figures.py` reads its numbers directly from
`experiments/results/*.json` rather than hardcoding any value — if you
re-run `experiments/run_all.py` (e.g. with larger sample sizes) and get new
numbers, just re-run `make_results_figures.py` afterward and Figures 3-5,
7, and 8 will update automatically to match. Figure 6 is a straight copy of
`experiments/results/context_metric_comparison.png`, so re-copy it manually
after any re-run of `run_all.py` if you want it to stay in sync too.

Edit the box text, colors, or layout constants at the top of each script and
re-run if you want to adjust anything before final submission (e.g. to
match a specific color scheme, or to add another module box).
